# Compliance Dashboard — Streamlit

لوحة مؤشرات تفاعلية لمكتبة الالتزام.

## ما الذي تفعله؟
- تقرأ Sheet `مكتبة الالتزام` من Excel.
- تحسب إجمالي الوثائق ونسب السريان والفحص والانطباق من البيانات نفسها.
- توفر 7 فلاتر تفاعلية.
- تعرض 4 رسوم بيانية.
- تقرأ Sheet `عداد_الأيام`.
- تحسب الأيام المتبقية من **تاريخ اليوم وتاريخ النفاذ**.
- تجعل دائرة العدّاد **تزداد اكتمالًا** كلما انخفضت الأيام المتبقية.
- زر `تحديث البيانات` يمسح الكاش ويعيد قراءة Excel.
- يمكن تشغيلها محليًا أو نشرها على Streamlit Community Cloud.

## تشغيل محلي
```bash
pip install -r requirements.txt
streamlit run app.py
```

## ربط Excel مركزي
للنشر العام، لا ترفعي ملف Excel الحقيقي إلى GitHub إذا كان يحتوي بيانات داخلية.

ضعي رابطًا مباشرًا لملف Excel في Streamlit Secrets:

```toml
[data]
excel_url = "رابط-مباشر-لملف-xlsx"
```

الرابط يجب أن يسمح للتطبيق بتنزيل ملف `.xlsx` مباشرة بدون صفحة تسجيل دخول.
إذا كان Excel على SharePoint/OneDrive خاصًا، نحتاج طريقة مصادقة مناسبة بدل رابط عام.

## النشر
1. أنشئي Repository على GitHub.
2. ارفعي `app.py` و`requirements.txt` فقط، ولا ترفعي `data/compliance.xlsx` إذا كانت البيانات حساسة.
3. افتحي Streamlit Community Cloud.
4. اربطي حساب GitHub.
5. اختاري Repository ثم `app.py`.
6. أضيفي `EXCEL_URL` في Secrets بالشكل أعلاه.
7. Deploy.
8. سيصبح لديك رابط عام يمكن مشاركته.

## ملاحظة أمنية مهمة
إذا كان الرابط Public والبيانات حساسة، فكل من يملك الرابط قد يستطيع رؤية البيانات. في بيئة عمل الهيئة، الأفضل لاحقًا تفعيل دخول Microsoft/Entra ID أو وضع التطبيق خلف وصول مؤسسي.
